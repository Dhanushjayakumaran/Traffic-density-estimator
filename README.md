# Traffic-density-estimator
An AI-powered Traffic Density Estimator built using Python, YOLO, OpenCV, and Streamlit. Detects vehicles in road images, estimates traffic density, and visualizes congestion. Integrates DSA concepts: Circular Linked List (CO2) for traffic record management, AVL Tree (CO3) for congestion analysis, and Graphs with DFS (CO5) for alternative route
